# HTML 메일 공통 조판 사양

`아침 통합 브리핑`에서 추출한 공통 사양이다. 새 루틴은 이 문서를 참조하고 사양을 복붙하지 않는다.
디자인 기준은 Chubb의 기업 브랜드 언어 — 흰 배경, 큰 제목, 넉넉한 여백, 머리카락 굵기의 가로선.
대시보드풍이 아니라 **편집물(editorial) 지면**처럼 짠다.

## 모바일 우선 — 가장 중요하다

수신자는 아이폰 메일로 읽는다. **고정폭을 쓰면 메일 앱이 지면 전체를 축소해 띄워 글자가 읽을 수
없게 작아진다.**

- `<table width="680">` 같은 **고정폭 속성을 쓰지 않는다.** 바깥 표는 `width="100%"`,
  안쪽 본문 표는 `width="100%"` + `style="max-width:680px"`.
- 안쪽 표·셀에 **px 고정폭을 주지 않는다.** 폭이 필요한 칸(번호·세로선·시각)만 20~62px.
- **좌우 여백 24px.** 40px은 375px 화면에서 본문을 너무 좁게 만든다.
- **3열 표를 쓰지 않는다.** 지표·환율 표는 **2열** — 왼쪽 칸에 항목명(16px)과 그 아래 비고
  (13px 보조색), 오른쪽 칸에 숫자(16px, `white-space:nowrap`). 일정 표는 시각(62px) + 내용 2열.
- 본문 컨테이너에 `word-break:keep-all` — 한국어 단어가 중간에 잘리지 않게.
- 본문 `line-height:1.7`, 표 행 상하 패딩 11px 이상.
- **미디어 쿼리에 기대지 않는다**(네이버 메일 등에서 제거될 수 있다). 미디어 쿼리 없이 375px에서
  읽히는 레이아웃으로 짠다.

## 타이포그래피

- **고딕(sans-serif)만 쓴다**:
  `-apple-system, BlinkMacSystemFont, 'Malgun Gothic', 'Apple SD Gothic Neo', '맑은 고딕', sans-serif`
  세리프(Georgia·바탕·명조)는 쓰지 않는다.
- **크기 4종만**: 제목 28px / 섹션·기사 제목 19px / 본문 16px / 라벨·각주 13~14px.
- **본문은 16px 아래로 내리지 않는다.** 13px은 표의 보조 설명과 작은 라벨에만.
- **전부 대문자 라벨을 쓰지 않는다**(브랜드 매뉴얼 금지). `text-transform:uppercase` 금지.
- **본문 강조에 굵게를 쓰지 않는다.** `font-weight:600`은 **제목에만**. 강조는 색과 여백으로.

## 색

| 용도 | 값 |
|---|---|
| 배경 | `#ffffff` (회색 배경 금지, 연한 밴드만 `#f7f7f7`) |
| 제목 글자 | `#212529` |
| 본문 글자 | `#3a3f44` |
| 보조 글자 | `#8a8f94` |
| 머리카락 선 | `#e3e3e3` |
| 구분선 | `#c9c9c9` |
| 포인트(청록, Chubb 로고색) | `#01c1d6` |
| 보조 강조(진한 파랑) | `#150f96` |
| 하락·안정 | `#0e7c86` |

상승 `▲ #150f96`, 하락 `▼ #0e7c86`.

## 구성

1. 상단에 `#212529` 6px 가로 밴드 → 흰 지면에 제목(28px, 600) → 그 아래 날짜·조사 범위 등을
   14px 보조색으로 `<br>`로 2~3줄 끊어서. **로고나 회사 마크는 넣지 않는다.**
2. 섹션 머리 — 위에 `#c9c9c9` 1px 선 + 청록 숫자 + 섹션명(19px, 600). 건수 표기는 좁은 화면에서
   제목을 밀어내므로 넣지 않는다.
3. 표 — **격자 테두리를 쓰지 않는다.** 행마다 아래쪽 `#e3e3e3` 1px 선만, 머리행은 13px 보조색 +
   아래 `#c9c9c9` 선. 숫자는 우측 정렬.
4. 카드 — 박스로 감싸지 않는다. 카드 사이는 `#e3e3e3` 1px 선으로만. 태그는 테두리 칩 대신
   13px 청록 글자를 가운뎃점으로. 중요 라벨은 `#f7f7f7` 밴드에 청록 라벨로.
   **가장 중요한 1건만** 왼쪽에 3px `#150f96` 세로선.
5. 출처는 14px, 링크 `#01c1d6` 밑줄 없음. 링크 사이 `line-height:2`로 터치 간격.
6. 맨 아래 `#c9c9c9` 선 아래 14px 보조색 각주.

## 공통

- 가운데 정렬, 최대폭 680px(고정이 아니라 상한).
- 모든 스타일은 **인라인 `style` 속성**. 웹폰트·외부 CSS·스크립트·다크모드 미디어쿼리를 쓰지 않는다.
- 레이아웃은 `<table>` 기반(네이버 메일·아웃룩 호환).
- 섹션 간 위아래 패딩 24px 이상.
