# HJ

두뇌 게임 모음. 전부 서버 없이 브라우저에서만 동작한다.

## 숫자야구 전광판

1~9 중 서로 다른 숫자를 스트라이크·볼 판정만으로 맞히는 웹 게임.

플레이: https://hjlim1007-web.github.io/HJ/

- 3자리는 9이닝, 4자리는 12이닝 안에 맞히면 승리
- 스트라이크(숫자·자리 일치) / 볼(숫자만 일치) / 아웃(전부 불일치)
- 마지막 자리를 입력하면 자동으로 투구
- 지금까지의 판정과 모순되지 않는 남은 정답 후보 수를 매 투구마다 표시
- 서버 없이 브라우저에서만 동작하며, 최소 이닝 기록은 각자 브라우저에 저장된다

## 라이트 아웃

한 칸을 누르면 그 칸과 상하좌우가 함께 뒤집히는 전구판을 모두 끄는 논리 퍼즐.

플레이: https://hjlim1007-web.github.io/HJ/lights-out.html

- 3×3 / 4×4 / 5×5, 난이도 3단계
- 매 수마다 **남은 최소 클릭 수**를 GF(2) 선형계로 풀어 실시간 표시 (헛수를 두면 바로 드러난다)
- 힌트는 최적 해에 포함된 칸 하나를 알려준다
- 난이도 구간은 각 판 크기에서 실제로 존재하는 최소 수의 분포를 전수 계산해 정했다
  (최소 수의 최댓값: 3×3은 9, 4×4는 7, 5×5는 15)

### 파일

| 파일 | 용도 |
| --- | --- |
| `baseball.html` | 숫자야구 본문. Claude 아티팩트로 발행하는 원본이라 `<head>`/`<body>` 골격이 없다 |
| `lightsout.html` | 라이트 아웃 본문 (위와 같은 형식) |
| `index.html` | 숫자야구의 GitHub Pages 배포본 (생성물, 직접 수정하지 않는다) |
| `lights-out.html` | 라이트 아웃의 GitHub Pages 배포본 (생성물) |
| `build-page.py` | 본문 파일들을 단독 문서로 감싸 배포본을 만드는 스크립트 |

본문 파일을 고친 뒤에는 `python3 build-page.py`로 배포본을 다시 만든다.

### Pages 설정

Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)`
